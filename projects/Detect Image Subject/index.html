    What is happening?

    How MobileNet Reads an Image

    Pre-trained model

    MobileNet is a pre-trained image classification model. TensorFlow.js lets it run directly in the browser, so the image can be analyzed on the page.

    Pattern matching

    The model predicts labels based on visual patterns it learned from training data. It returns probabilities, which this app displays as confidence percentages and bars.

    Limitations

    MobileNet does not truly understand images like a human. Results can be wrong if the image is blurry, cropped, unusual, stylized, or outside the model's training categories.
