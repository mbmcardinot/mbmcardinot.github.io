# Creative Coding for Game Art Students

## Assignment

PROG 102 JavaScript Site
Mella Cardinot

## Description

This project is a beginner friendly one page website about creative coding for game art students. It uses plain HTML, CSS, and JavaScript to create a small study site with navigable sections, theme switching, a creative prompt generator, and a filterable gallery.

The project was inspired by the class demo using `nav` buttons, `data-page` attributes, `.page` sections, and `.active` classes.

## Files Included

- `index.html` - Main HTML page for opening the project in a browser.
- `style.css` - Visual design, layout, themes, cards, and responsive styles.
- `script.js` - Navigation, saved theme, saved page, prompt generator, and gallery filters.
- `README.md` - Project notes and instructions.

## Features

- Four navigable sections: Home, About, Gallery, and Resources.
- Navigation buttons that show and hide page sections.
- Active navigation button highlighting.
- Dark and light theme toggle.
- Theme choice saved with `localStorage`.
- Last visited section saved with `localStorage`.
- Random creative prompt button on the Home page.
- Gallery filter buttons for All, Code, Art, and Game.
- Responsive layout for desktop and mobile screens.

## How to Run the Project

Open `index.html` directly in a web browser.
