What It Means

Code can be an art material.

Creative Coding

Creative coding means writing programs to make visual, playful, or interactive work. Instead of only solving business problems, the code becomes part of the artwork.

Game Art Connection

Game artists can use JavaScript to test color palettes, build animated mockups, design menus, create particle effects, or prototype character interactions before moving into a larger game engine.

Beginner Mindset

Each small experiment teaches a skill: selecting elements, responding to clicks, changing classes, storing choices, and making the browser react to the player or viewer.
