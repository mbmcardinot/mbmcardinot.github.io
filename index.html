The Price of a Future Tuition chart • Debt calculator • Student stories

Project: Interactive Work

The Price of a Future

This final interactive project explores affordable education through tuition projections, a debt calculator, student stories, and action steps. It combines research, data visualization, and interactive design to help students understand how college costs affect real decisions.

Challenge

The challenge was turning a large societal issue into something understandable, personal, and interactive.

How I solved it

I used an interactive chart, calculator, and story cards to connect abstract cost data to student experiences. The project balances information with emotion so users can understand the problem and imagine practical next steps.

  • HTML
  • CSS
  • JavaScript
  • Chart.js
  • Social Impact

Technical details: Built as a multi-section website with smooth navigation, responsive cards, Chart.js visualization, input validation, and a cost calculator that updates automatically.

Creative Coding Site Navigation • Theme toggle • Gallery filters

JavaScript Site

Creative Coding for Game Art Students

A multi-section JavaScript website using navigation buttons to switch between content sections without reloading the page. The site connects creative coding concepts to game art and interactive media.

Challenge

The challenge was understanding how JavaScript controls page state and updates what the user sees.

How I solved it

I used navigation buttons with data-page attributes, matching section IDs, and active classes to show and hide content. I added localStorage, a theme toggle, a prompt generator, and gallery filters to deepen the interaction.

  • DOM
  • Events
  • classList
  • localStorage

Concepts: querySelectorAll, event listeners, dataset values, class toggling, responsive CSS, and beginner-friendly state management.

Weather Data Visualization

World Weather Dashboard

This dashboard presents weather information in a simple, visual layout using HTML, CSS, and JavaScript. It organizes city-based weather values into readable cards.

  • Data

AI Doodle Classifier p5.js canvas • ml5.js • confidence scores

Doodle App (ML)

AI Doodle Classifier

A drawing app built with p5.js and ml5.js that uses DoodleNet to guess what the user is drawing. The app includes controls for clearing, saving, and testing doodles.

Challenge

The challenge was connecting a creative drawing interface to a machine learning model in the browser.

How I solved it

I created a p5.js canvas, added mouse drawing logic, loaded DoodleNet through ml5.js, and displayed the model’s top predictions with confidence values so users could understand the AI output.

  • p5.js
  • ml5.js
  • DoodleNet
  • Canvas

Technical details: Uses the classification loop from the starter demo and improves it with clearer visual feedback, brush controls, and screenshot-ready layout.

Sentiment Analyzer Text input • Stars • Meter • History

Sentiment (Customized)

Movie Review Sentiment Analyzer

A customized sentiment analysis tool that scores text from negative to positive and displays the result through stars, emoji, a meter bar, and recent prediction history.

Challenge

The challenge was making a numeric machine learning score understandable through a simple user interface.

How I solved it

I translated the sentiment score into a percentage, category label, stars, emoji, and meter bar. I also added examples and history so users could compare different text inputs.

  • ml5.js
  • Sentiment
  • DOM Updates
  • Conditionals

Model note: The model is trained on movie reviews, so the project includes a limitations note and presents predictions as approximate pattern-based results.

Process

How this portfolio came together

I started with HTML, CSS, and basic JavaScript interactions, then moved into DOM selection, event listeners, class toggling, localStorage, p5.js creative coding, ml5.js machine learning, TensorFlow-style image/sentiment concepts, and data visualization for interactive storytelling.

Each project card explains the assignment challenge and how I solved it, so the portfolio shows both finished work and the thinking behind the code.
